# intro_to_ml

Лабораторные работы по курсу «Введение в машинное обучение».

Сквозной датасет большинства работ — [`lapki/perekrestok-reviews`](https://huggingface.co/datasets/lapki/perekrestok-reviews): ~642 тыс. русскоязычных отзывов о товарах магазина «Перекрёсток» (текст отзыва, рейтинг, категория и цена товара). Исключение — лаба 3, где используется датасет Communities and Crime.

## Структура

- [lab_works/](lab_works/) — ноутбуки с лабораторными работами. Датасеты подгружаются из кода, в репозитории не хранятся.
- [lab_reports/](lab_reports/) — письменные отчёты по работам в формате `.docx` и документ с целями и задачами курса.

## Лабораторные работы

### Лаба 1 — EDA и знакомство с данными
[lab_works/lab_1_eda.ipynb](lab_works/lab_1_eda.ipynb)

Разведочный анализ датасета отзывов: загрузка, разбор признаков по типам (числовые, категориальные, текстовые, идентификаторы), статистика числовых признаков (среднее, медиана, мода, дисперсия, квантили), поиск проблем качества данных (пропуски, дубликаты, аномальные рейтинги и цены).

### Лаба 2 — Предобработка и векторизация текста
[lab_works/lab_2_preproccess.ipynb](lab_works/lab_2_preproccess.ipynb)

Очистка данных и текстовый конвейер: нижний регистр, удаление пунктуации, токенизация, стоп-слова, лемматизация. Векторизация через Bag of Words и TF-IDF, сравнение представлений (размерность, разреженность, примеры векторов). Отдельно разобран подбор стоп-слов под задачу тональности — какие служебные слова оставить (отрицания, оценки), а какие убрать.

### Лаба 3 — Регрессия и снижение размерности
[lab_works/lab_3_regression.ipynb](lab_works/lab_3_regression.ipynb)

Датасет Communities and Crime (прогноз уровня насильственных преступлений). Снижение размерности методами PCA и Truncated SVD с выбором числа компонент по накопленной объяснённой дисперсии (124 → 31 признак, ~90 % дисперсии); собственная реализация PCA через ковариационную матрицу и сверка со sklearn. Линейная, полиномиальная регрессия и регуляризация с самостоятельной реализацией метода наименьших квадратов.

### Лаба 4 — Кластеризация
[lab_works/lab_4_clasterization.ipynb](lab_works/lab_4_clasterization.ipynb)

Кластеризация отзывов на TF-IDF/SVD-представлении пятью методами: K-Means, K-Means++, MiniBatch K-Means, плотностный (DBSCAN) и иерархический (агломеративный, метод Уорда). Подбор `K` методом локтя, подбор параметров DBSCAN перебором `min_samples × eps`, эксперимент с влиянием размерности. Математическое описание DBSCAN и агломеративной кластеризации, сравнение методов по качеству и скорости.

### Лабы 5–6 — Классификация
[lab_works/lab_5-6_classification.ipynb](lab_works/lab_5-6_classification.ipynb)

Классификация тональности отзывов. Инженерия признаков (анализ эмодзи, признак структурированности, шаблонные ярлыки формы отзыва), разбиение train/validation/test с CV-фолдами. Полный набор классификаторов, включая четыре варианта наивного Байеса, и собственная реализация MultinomialNB с нуля с построчной сверкой со sklearn. Подбор гиперпараметров, снижение размерности (TruncatedSVD), ROC/PR-кривые, `classification_report`, сравнение пайплайнов BoW и TF-IDF.

### Лаба 7 — Подбор гиперпараметров и ансамблирование
[lab_works/lab_7_ensembles.ipynb](lab_works/lab_7_ensembles.ipynb)

Единый `Pipeline` (векторизация + снижение размерности + модель), подбор всего пайплайна через Optuna (45 trial). Четыре ансамбля на выбранном представлении, выбор метода по validation и дообучение на train+val, итоговая оценка на test. Парный bootstrap по товарам для оценки значимости различий, сохранение модели и прогнозирование.
